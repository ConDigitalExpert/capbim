# Capbim

Capture-to-BIM desk. Plan the photographs with the Fraser / GSD predictor, run the QC gates, measure the room, and sign a rehearsal statement.

Later stages obey the threshold file on a parametric room. They are not a Metashape survey, and a signed statement is not a certificate.

```bash
npm install
npm run dev
```
